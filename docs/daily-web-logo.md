# The Daily Web logo

Generated with the built-in image generation tool. Transparent PNG assets:

- `public/img/daily-web-logo.png`: 256 × 256, for the site header and auth screens.
- `public/img/daily-web-favicon.png`: 32 × 32, for browser tabs.
- `public/img/daily-web-touch-icon.png`: 180 × 180, for saved shortcuts.

The raster mark is paired with the existing live-text site name for accessible, readable branding.

## Generation prompt

Use case: logo-brand. Design a polished original logo symbol for 'The Daily Web', a contemporary digital newspaper. Asset is a standalone square brand mark, NOT a full website mockup. A bold geometric folded newspaper forms a distinctive capital D silhouette, with three clean horizontal negative-space editorial lines and a small globe-inspired arc integrated into the silhouette. Minimal flat graphic design with crisp edges, deep forest green #234237 and warm ivory details, quiet premium editorial character. A compact balanced silhouette that remains legible as a favicon at 32 pixels; use only a few bold shapes, no hairline detail. Center the symbol and let it fill approximately 85 percent of the square. Transparent background. No text, no wordmark, no mockups, no gradients, no shadows, no 3D, no watermark.
